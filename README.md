# Santhosh Kumar N — Personal Portfolio

A modern, cinematic personal portfolio website for **Santhosh Kumar N**, focused on software engineering, backend development, AI-powered applications, APIs, databases, testing, and cloud-ready engineering.

## ✨ Highlights

- Cinematic dark UI with a restrained red-accent design system
- Intro screen: the SK logo draws in with a progress counter, waits for the page, fonts and first hero frame (6-7s at most), then a curtain opens onto the hero. Skipped with reduced motion.
- Per-element scroll reveals with staggered, eased transitions (no heavy full-screen overlays)
- Animated mobile menu sheet: tap outside or press Escape to close, hides on scroll down and returns on scroll up
- Responsive from 320px phones to wide desktops, with 44px minimum tap targets and no horizontal overflow
- Scroll-driven WebM hero background that fades out smoothly; the first frame paints immediately on phones
- Eight project cards; each system-architecture diagram collapses behind a toggle on mobile and opens a detail dialog when a node is clicked
- Skills matrix, four-step working process, and a Research & credentials section with publication and certification cards
- Quick-navigation dialog (Ctrl/Cmd + K), scroll progress bar, active-section highlighting, scroll-to-top button
- Hero line that types through focus areas (backend systems, REST APIs, AI & OCR pipelines, realtime apps)
- Animated count-up stats, a cursor spotlight on cards, and a dot rail that tracks the current section on wide screens
- Project filters (All / Backend / Full-stack / AI & ML) with live counts
- Built-in terminal: press `` ` `` or use the footer button, then try `help`, `projects`, `project 2`, `skills`, `goto contact`, or `sudo hire-me`
- Contact form that opens your email client (no backend needed), plus copy-email and direct GitHub, LinkedIn, and WhatsApp links
- Custom cursor on fine pointers only
- Full `prefers-reduced-motion` support, and content stays visible if JavaScript is off
- SEO and social sharing metadata

## 🎨 Portfolio Design & Interaction

The website is implemented without a frontend framework and uses browser-native APIs and static assets.

- CSS custom properties for colour, spacing, radius, and motion easing
- Progressive-enhancement reveal system built on `IntersectionObserver`
- Canvas-based scroll-scrubbed background video
- Responsive layout driven by media queries and fluid `clamp()` spacing
- Accessible by default: skip link, `aria-current` on the active section, labelled controls, visible focus states
- Native `<dialog>` elements for quick navigation and architecture details

## 📁 Repository Structure

```text
Personal-portfolio/
├── .github/workflows/deploy.yml   # GitHub Pages deploy (no build step)
├── index.html                     # all markup and content
├── style.css                      # the single stylesheet
├── script.js                      # the single script
├── background-animation.webm      # scroll-scrubbed hero video
├── og-image.jpg                   # social-share preview (1200x630)
├── favicon.svg
└── README.md
```

`index.html` links `style.css` and `script.js` directly, so the code in this repository is exactly what gets deployed. `style.css` is organised into numbered sections (tokens and base, navigation, sections, project cards, architecture diagrams, responsive rules), and `script.js` into nine numbered sections (background video, reveals, navigation, dialogs, architecture panels, cursor, contact, scroll chrome, extras).

## 🚀 Run Locally

This is a static website and does not require package installation for the basic version.

Open `index.html` directly in a modern browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🌐 Deployment

As a static HTML/CSS/JavaScript site, the portfolio can be deployed to GitHub Pages, Vercel, Netlify, Cloudflare Pages, or another static web server.

The repository uses the `main` branch. Every push to `main` runs `.github/workflows/deploy.yml`, which checks that every local asset referenced by `index.html` exists and then publishes the folder to GitHub Pages.
